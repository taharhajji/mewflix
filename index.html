Choisir son appareil

Windows

Windows 10 ou 11, 64 bits.

Installer Version portable
Comment installer
  1. Télécharger Installer et l'ouvrir.
  2. Si Windows affiche « Windows a protégé votre ordinateur » : cliquer Informations complémentaires puis Exécuter quand même. L'app n'a pas de certificat payant, c'est tout.
  3. MEWFLIX s'ouvre et un raccourci est créé sur le Bureau.
  • La version portable se lance sans installation (clé USB possible), mais ne se met pas à jour toute seule.
  • Mode TV (PC branché sur une télé, téléphone en télécommande) : bouton « Mode TV » dans la barre du haut, ou touche F9.

macOS

Un seul fichier selon le Mac (menu Pomme → À propos de ce Mac → « Puce »).

Mac puce Apple (M1 à M4) Mac Intel
Comment installer
  1. Double-cliquer sur le zip : il donne MEWFLIX.app. La glisser dans Applications.
  2. Premier lancement : macOS dit qu'il ne peut pas vérifier l'app → OK. Puis Réglages Système → Confidentialité et sécurité → en bas, « MEWFLIX a été bloqué » → Ouvrir quand même. (macOS 14 ou plus ancien : clic droit sur l'app → Ouvrir.)
  3. Si macOS dit « MEWFLIX est endommagé » : le fichier n'est pas abîmé. Cliquer Annuler, ouvrir Terminal (Applications → Utilitaires) et coller :
    xattr -cr /Applications/MEWFLIX.app
    Puis relancer MEWFLIX.

Chromebook / Linux

Linux doit être activé sur le Chromebook. Sur un PC Linux (Debian, Ubuntu…), même fichier.

Intel / AMD ARM (MediaTek, Snapdragon)
Comment installer
  1. Activer Linux une fois : Paramètres → Avancés → Développeurs → « Environnement de développement Linux » → Activer.
  2. Pour savoir quel fichier prendre : taper chrome://version dans Chrome, ligne « Platform » : x86_64 = Intel/AMD, aarch64 = ARM.
  3. Copier le .deb dans « Fichiers Linux » (app Fichiers), double-cliquer dessus → Installer. MEWFLIX apparaît dans le lanceur, dossier « Applications Linux ».
  4. Si l'installation réclame des bibliothèques, dans l'app Terminal :
    sudo apt install -y ./MEWFLIX-*-linux-amd64.deb
    (ou …-arm64.deb selon le fichier).

Android TV télé

Télés et boîtiers Android TV / Google TV (TCL, Sony, Philips, Xiaomi, Chromecast avec Google TV…). Tout se fait à la télécommande.

is.gd/mewflixtv
Télécharger l'APK
Comment installer (10 minutes)
  1. Sur la télé, ouvrir le Google Play Store et installer l'appli Downloader (icône orange, éditeur AFTVnews).
  2. Dans Downloader, écrire l'adresse is.gd/mewflixtv puis Go.
  3. La télé bloque les applis hors Play Store : appuyer sur Paramètres dans le message, activer Downloader, puis Retour.
    Sinon : Paramètres → Applications → Sécurité et restrictions → Sources inconnues → Downloader.
  4. Installer → Terminé, puis supprimer le fichier téléchargé (Delete) : ça ne supprime pas l'appli.
  5. Bouton Maison → Applications → MEWFLIX.
  • Flèches pour se déplacer, OK pour choisir, Retour pour revenir. Flèche gauche au bord : menu.
  • Pas de mise à jour automatique sur télé : refaire les étapes 2 à 4 avec la même adresse pour installer une nouvelle version par-dessus.
